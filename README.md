# ToDo

A simple and minimal todo app built with React and Tailwind CSS. You can add, edit, delete, and mark tasks as complete. It also saves everything in localStorage so your tasks don’t disappear on refresh.

## Features

- Add new tasks  
- Edit and delete tasks  
- Mark tasks as done  
- Show/hide completed tasks  
- Saves data in localStorage  
- Mobile responsive  

## Getting Started

Make sure you have Node.js and npm installed.
