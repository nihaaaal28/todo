# ToDo App

A simple and minimal dynamic responsive todo app built with React and Tailwind CSS. You can add, edit, delete, and mark tasks as complete. It also saves everything in localStorage so your tasks don't disappear on refresh.

## Features

- Add new tasks  
- Edit and delete tasks  
- Mark tasks as done  
- Show/hide completed tasks  
- Saves data in localStorage  
- Mobile responsive  

## Getting Started

Make sure you have Node.js and npm installed.

### 1. Clone the repo

```bash
git clone https://github.com/nihaaaal28/todo.git
cd todo
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm run dev
```

Then open your browser and go to:

```
http://localhost:5173
```
